# 🏏 IPL Data Analysis Dashboard (2008–2025) | Power BI

## 📌 Project Overview

This project presents an interactive **Indian Premier League (IPL) Data Analysis Dashboard** built using Microsoft Power BI. It analyzes IPL match data from **2008 to 2025** to uncover insights into team performance, match results, player achievements, and tournament trends.

The dashboard helps users explore historical IPL data through interactive visualizations, charts, KPIs, and filters.

## 🎯 Project Objectives

* Analyze IPL match statistics from 2008 to 2025.
* Identify the most successful teams and their performances.
* Explore season-wise winners and runners-up.
* Analyze toss decisions and their impact on match results.
* Identify top-performing players and match award winners.
* Present cricket insights through an interactive Power BI dashboard.

## 📊 Dashboard Features

* **Season Analysis:** Explore IPL trends across different seasons.
* **Team Performance:** Compare team wins and overall performance.
* **Season Winners:** Display the IPL champion for each season.
* **Runner-up Analysis:** Identify the finalist who finished second.
* **Player Performance:** Analyze player achievements and awards.
* **Toss Analysis:** Explore toss winners and toss decisions.
* **Match Analysis:** Examine match outcomes and winning margins.
* **Interactive Filters:** Filter data by season, team, and other available categories.

## 🛠️ Tools & Technologies
